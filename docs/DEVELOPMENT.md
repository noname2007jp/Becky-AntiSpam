# 開発メモ

## 確認済みの公開情報

- RimArts の公式ページに Becky! Plug-In SDK の案内がある。
- SDK のヘルプは英語。SDKに含まれる `BeckyApi.h` と `PluginSDK.txt` が実装の一次資料となる。
- 公開されている Becky! プラグインの解説では、受信メールソースを受け取る `OnRetrieve` コールバックが紹介されている。ただし、これは第三者ライブラリの資料であり、公式SDKのバージョン・ABIと照合が必要。

## 実装前に必ず確認すること

1. SDKの最新版を入手し、ライセンス・再配布条件を確認する。
2. Becky!本体とSDKの64bit対応状況、プラグインDLLのビット数・呼出規約を確認する。
3. 受信時コールバックの引数文字コード、メールソースの寿命、スレッド条件を確認する。
4. メール移動・ラベル付与・フォルダ操作に公式APIがあるか確認する。
5. SDKの実ヘッダーをプロジェクトに追加し、最小のロード確認プラグインを作成する。

## 実装上の安全策

- 最初は判定結果をログへ出すだけの監査モードとする。
- 自動振り分けはユーザーが明示的に有効化した場合だけ動作させる。
- 削除は実装しない。迷惑メール用フォルダへの移動のみを検討する。
- SPF/DKIM/DMARCは、受信側サーバーが付与した認証結果を信頼境界を考慮して利用する。ヘッダー文字列だけで真正性を断定しない。
- 添付ファイルは開かず、初期段階では解析対象外とする。
- 学習データとログはローカル保存し、メール本文をログに残さない。

## 現在のエンジンの制限

初期エンジンは判定方式の骨格であり、本番向けスパム判定器ではない。日本語トークナイズ、MIMEデコード、HTML本文抽出、ヘッダー重複・偽装対策、永続化、誤判定評価は今後の課題。
