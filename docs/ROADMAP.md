# 開発ロードマップ

更新日: 2026-11-06

## 開発ターゲット
- Becky! Internet Mail 2.83.11（x86）
- Windows x64上で動作するWin32/x86 DLL
- Visual Studio 2022 / CMake / Windows x86 CI

## フェーズ

| Phase | 内容 | 完了条件 |
|---|---|---|
| 0 | 仕様・SDK確認 | 機能仕様とSDK制約を文書化 |
| 1 | 最小プラグイン基盤 | Win32 DLLがBecky! 2.83.11でロードされる |
| 2 | メール解析 | サイズ制限付きヘッダー/MIME/本文抽出 |
| 3 | ローカル判定 | ルール・リスト・Bayes・判定理由 |
| 4 | 学習DB | SQLite永続化、重複防止、バックアップ、スリム化 |
| 5 | 手動操作 | 手動判定、学習、再判定、一括操作 |
| 6 | 補助判定 | URL/添付/言語/GeoIP等を段階追加 |
| 7 | AI API | 非同期再判定、仮ラベル、ユーザー確認後の学習 |
| 8 | 自動振り分け | 監査試験後に明示設定で有効化 |
| 9 | 運用試験 | 誤検知、見逃し、性能、DB肥大化、復元試験 |

## 直近の作業順
1. 現行エンジンの単体テストと判定ロジックを改善。
2. 語彙上限・統計・安全な学習データ整理APIを実装。
3. SQLiteのWin32統合方法とスキーマを決定。
4. SDKを使った最小DLLを実装し、実機ロードを確認。
5. MIME解析と日本語トークナイズを追加。

## リリースゲート
- DLLのロード成功をCI成功と混同しない。実機確認を別途記録する。
- 自動振り分けは監査モードの結果を確認してから解放する。
- AI連携はローカル判定・学習・DB管理が安定するまで初期OFFのまま。
- DBスリム化後に判定精度が許容範囲内であることを回帰テストする。

## スケジュール目安
約8週間を初期目安とする。ただし、SDK実機互換性、MIME実装、日本語辞書のライセンス・配布方法、AI APIの試験により延長する。週数は保証納期ではなく作業計画。
